
# MVP - Gestão Rede Cananéia

Sistema web para gerenciamento de solicitações de uma associação comunitária.

## Objetivo
Organizar o cadastro, a consulta e o acompanhamento de solicitações.

## Funcionalidades
- Autenticação de usuários
- Cadastro de solicitações
- Consulta de solicitações
- Atualização de status

## Tecnologias previstas
- Python
- Flask
- HTML e CSS
- PostgreSQL
- SQLAlchemy

## Projeto acadêmico
Desenvolvido como parte do curso de Análise e Desenvolvimento de Sistemas.
